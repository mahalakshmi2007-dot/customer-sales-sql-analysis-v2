# Customer & Sales Data Analysis Using SQL

## 📌 Project Overview

This project analyzes customer and sales data using SQL to identify
important business insights related to revenue, profit, customers,
products, regions, and sales performance.

## 🛠️ Tools Used

- SQL
- SQLite
- SQLiteOnline
- VS Code
- GitHub

## 📊 Analysis Performed

- Total Revenue
- Total Profit
- Highest Sales Order
- Top 5 Customers
- Best-Selling Product
- Best Performing Region
- Category Performance
- Salesperson Performance
- Above-Average Sales Orders
- High / Medium / Low Sales Classification
- Monthly Sales Analysis
- Average Order Value
- Minimum and Maximum Sales
- Regional Sales and Profit Analysis

## 🎯 Business Questions

The project uses SQL to answer practical business questions such as:

1. What is the total revenue?
2. What is the total profit?
3. Which order has the highest sales?
4. Who are the top customers?
5. Which product generates the highest revenue?
6. Which region performs best?
7. Which category generates more sales and profit?
8. Which salesperson performs best?
9. Which orders are above average?
10. How are orders classified by sales value?
